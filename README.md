## 🎯 Proje Tanıtımı

**PDF Atölyesi**, PDF dosyalarını **birleştirmek** ve **sayfa aralıklarına göre ayırmak** için geliştirilmiş modern, hızlı ve **tamamen güvenli** bir masaüstü uygulamasıdır.

### 🔒 Güvenlik & Gizlilik Garantisi

| Özellik | Detay |
|---|---|
| 🌐 **İnternet bağlantısı gerektirmez** | Tüm işlemler bilgisayarınızda yerel olarak çalışır |
| 🚫 **Hiçbir veri gönderilmez** | PDF'leriniz hiçbir sunucuya yüklenmez |
| 🛡️ **Tahribatsız işlem** | Orijinal dosyalarınız **asla** değiştirilmez |
| 📋 **Kopya mantığı** | Her işlemde yeni bir PDF dosyası oluşturulur |

---

## ✨ Özellikler

### 🔗 PDF Birleştirme
- Birden fazla PDF dosyasını **tek dosyada** birleştirin
- Liste üzerinden **sıralamayı değiştirin** (⬆️ / ⬇️)
- İstemediğiniz dosyaları listeden **kaldırın** (❌)
- Birleştirmeden önce her dosyayı **canlı önizleme** ile kontrol edin
- Çıktı dosyasının adını ve konumunu **tamamen siz belirleyin**

### ✂️ Sayfa Ayırma
- Bir PDF'ten istediğiniz sayfaları **görsel küçük resim** üzerinden seçin
- Esnek **sayfa aralığı** desteği: `1-3,5,8-10`
- Seçtiğiniz sayfalar otomatik olarak aralık kutusuna yansır
- Manuel aralık girişi de desteklenir
- Çıktı dosyası yine **yeni bir kopya** olarak kaydedilir

### 🎨 Arayüz
- 🌙 / ☀️ **Dark / Light tema** desteği
- 🏠 **Ana Sayfa** butonu ile modlar arası geçiş
- ❓ **Bağlamsal yardım** (her moda özel "Nasıl Kullanılır?" rehberi)
- 📊 Alt **durum çubuğu** ile işlem bildirimleri
- 🖼️ **Canlı PDF önizleme** (PyMuPDF ile hızlı render)
- 🎯 **Ekran ortasında** açılış — her çözünürlükte hizalı

### 🧩 Teknik
- ✅ **Tek dosya .exe** — kurulum gerektirmez
- ✅ **Bağımsız** — Python, DLL veya ek paket gerekmez
- ✅ **Taşınabilir** — USB belleğe atıp başka bilgisayarda çalıştırın
- ✅ **Kurulumsuz** — Windows'un herhangi bir sürümünde çalışır

## 🚀 Tıkla-Çalıştır — .exe ile Kullanım (Kurulum Gerekmez)

> ⚡ **Kod, Python veya ek kurulum gerekmez. Sadece çift tıklayın!**

### 📥 1. Doğru Dosyayı İndirin
Uygulamanın çalıştırılabilir dosyası şu konumdadır:

```text
📁 Proje Klasörü
└── 📁 dist
    └── 🎯 PDF-Atolyesi_EnginARSLAN.exe ← BU DOSYA
```

- **İndirmeniz gereken tek dosya:** `dist/PDF-Atolyesi_EnginARSLAN.exe`

### 🖱️ 2. Çift Tıklayın
`PDF-Atolyesi_EnginARSLAN.exe` dosyasına **çift tıklayın** — uygulama açılır. Başka hiçbir şey yapmanıza gerek yok.

### ✅ 3. Kullanmaya Başlayın
Karşılama ekranından yapmak istediğiniz işlemi seçin:
- 🔗 **PDF Birleştir** → birden fazla PDF'i tek dosyada toplama
- ✂️ **Sayfa Ayır** → belirli sayfaları ayrı PDF olarak çıkarma

---

### ⚠️ ÖNEMLİ — Sadece 1 Dosya Yeter

> 🎯 **`dist/PDF-Atolyesi_EnginARSLAN.exe` dosyası tamamen bağımsızdır.**
>
> Yukarıdaki `.exe` dosyası **haricinde** proje klasöründeki **hiçbir dosyaya ihtiyacınız yoktur**:
>
> - ❌ `Application-Anasayfa.py` — **gerekmez**
> - ❌ `build/` klasörü — **gerekmez**
> - ❌ `.spec` dosyası — **gerekmez**
> - ❌ `README.md` — **gerekmez** (bu dosyayı okuyorsanız yeterli)
> - ❌ Python kurulumu — **gerekmez**
> - ❌ Herhangi bir kütüphane — **gerekmez**
>
> Sadece **`PDF-Atolyesi_EnginARSLAN.exe`** dosyasını indirmeniz yeterlidir.
> Diğer dosyaları bilgisayarınıza indirmenize **gerek yoktur**; boşuna disk alanı kaplamayın.
>
> Bu tek dosyayı masaüstüne, USB belleğe veya herhangi bir klasöre kopyalayıp **her yerde çalıştırabilirsiniz**.

### 💾 Taşınabilirlik
- 📌 Masaüstüne kopyalayın → çalışır
- 📌 USB belleğe atın → başka bilgisayarda çalışır
- 📌 İnternet bağlantısı olmadan → çalışır
- 📌 Kurulum gerektirmez → sadece çift tıkla

### 🎬 İlk Açılış
Uygulamayı ilk kez açtığınızda **Windows SmartScreen** uyarısı görürseniz:
1. **"Daha fazla bilgi"** bağlantısına tıklayın
2. **"Yine de çalıştır"** butonuna basın

Bu uyarı, `.exe` dosyasının dijital imzası olmadığı için Windows tarafından gösterilir. **Normaldir** ve güvenle çalıştırabilirsiniz.

## 📖 Kullanım Rehberi

### 🔗 PDF Birleştirme
1. Karşılama ekranında **PDF Birleştir** kartındaki **▶ Başla** butonuna tıklayın.
2. **➕ Ekle** butonuyla PDF dosyalarınızı seçin (birden fazla seçebilirsiniz).
3. Listeden bir dosyaya tıklayın → **sağ tarafta önizleme** görünür.
4. **⬆️ / ⬇️** ile sıralamayı düzenleyin.
5. İstemediğiniz dosyaları **❌ Kaldır** ile listeden çıkarın.
6. **🚀 PDF'leri Birleştir ve Kaydet** butonuna tıklayın.
7. Dosya adı ve konum seçin → **Kaydet**.

> ⚠️ Birleştirme için **en az 2 PDF** gerekir.

---

### ✂️ Sayfa Ayırma
1. Karşılama ekranında **Sayfa Ayır** kartındaki **▶ Başla** butonuna tıklayın.
2. **📂 PDF Seç** ile ayırmak istediğiniz dosyayı yükleyin.
3. Sayfalar **küçük resim** olarak listelenir.
4. İstediğiniz sayfalara **tıklayarak seçin** (mavi kenarlıklı olur).
5. Seçimler **Sayfa Aralığı** kutusuna otomatik yazılır.
6. İsterseniz kutuya manuel olarak `1-3,5,8-10` yazabilirsiniz.
7. **✂️ Ayır ve Kaydet** butonuna tıklayın → dosya adı ve konum belirleyin.

---

### 📐 Sayfa Aralığı Sözdizimi

| Giriş | Anlamı |
|---|---|
| `5` | Sadece 5. sayfa |
| `1-3` | 1, 2 ve 3. sayfalar |
| `1-3,5,8-10` | 1, 2, 3, 5, 8, 9, 10. sayfalar |

> 💡 Sayfalar **1'den** başlar. Geçersiz bir sayfa numarası girerseniz uyarı alırsınız.

## 🛠️ Geliştiriciler İçin

Kaynak kodu ile çalıştırmak, özelleştirmek veya katkıda bulunmak isteyenler için:

### 📋 Gereksinimler
- **Python 3.9+**
- İşletim sistemi: Windows / Linux / macOS

### 📦 Bağımlılıklar
```bash
pip install pypdf pymupdf customtkinter pillow
```

| Paket | Amaç |
|---|---|
| `pypdf` | PDF birleştirme & ayırma |
| `pymupdf` | PDF render (önizleme + küçük resimler) |
| `customtkinter` | Modern GUI |
| `pillow` | Görüntü işleme |

### ▶️ Çalıştırma
```bash
python Application-Anasayfa.py
```

### 🗂️ Proje Yapısı
```text
PDF-Atolyesi/
├── Application-Anasayfa.py           # Ana uygulama (GUI + PDF motoru)
├── README.md                         # Bu doküman
├── build/                            # PyInstaller geçici dosyaları (otomatik)
├── dist/
│   └── PDF-Atolyesi_EnginARSLAN.exe  # 🎯 Derlenmiş çalıştırılabilir dosya
└── PDF-Atolyesi_EnginARSLAN.spec     # PyInstaller spec dosyası (otomatik)
```

## 📦 Derleme (.exe Üretimi)

Kendiniz `.exe` üretmek istiyorsanız:

### 1️⃣ PyInstaller'ı Kurun
```bash
pip install pyinstaller
```

### 2️⃣ Derleyin
```bash
pyinstaller --noconfirm --onefile --windowed --clean --name "PDF-Atolyesi_EnginARSLAN" --collect-all customtkinter --collect-all pymupdf --hidden-import PIL._tkinter_finder Application-Anasayfa.py
```

**Komut parametreleri:**
| Parametre | Açıklama |
|---|---|
| `--onefile` | Tüm bağımlılıkları tek .exe içine gömer |
| `--windowed` | Konsol penceresi açmaz (GUI uygulaması için) |
| `--clean` | Önbelleği temizler |
| `--name "..."` | Çıktı dosya adı |
| `--collect-all customtkinter` | Tema ve font dosyalarını dahil eder |
| `--collect-all pymupdf` | PyMuPDF C bağımlılıklarını toplar |

### 3️⃣ Çıktıyı Alın
```text
dist/PDF-Atolyesi_EnginARSLAN.exe
```

### 🔄 Tekrar Derleme
Bir kere derledikten sonra `.spec` dosyası ile tekrar derleme:
```bash
pyinstaller "PDF-Atolyesi_EnginARSLAN.spec"
```

## ❓ Sorun Giderme

### 🚨 .exe açılmıyor / hemen kapanıyor
- Antivirüs `.exe`'yi engelliyor → istisna ekleyin
- Dosya bozuk indirilmiş → yeniden indirin
- Windows SmartScreen uyarısı → "Yine de çalıştır" seçin

### 🚨 Önizleme görünmüyor
- **Neden:** PyMuPDF (`fitz`) yüklenmemiş olabilir.
- **Çözüm:** Derlerken `--collect-all pymupdf` parametresini kullandığınızdan emin olun. Uygulama PyMuPDF olmadan da çalışır (birleştirme + ayırma işlemleri sorunsuz), sadece önizleme ve küçük resimler devre dışı kalır.

### 🚨 "Windows korumalı bilgisayarınızı korudu" uyarısı
- Bu, PyInstaller'ın imzasız `.exe` üretmesinden kaynaklanır. Normaldir. Detaylar → "Yine de çalıştır" seçin.

### 🚨 PDF açılmıyor / bozuk hatası
- Şifreli PDF'ler desteklenmez.
- Başka bir okuyucuda açılıp açılmadığını test edin.
- PDF bozuksa başka bir kaynaktan edinin.

### 🚨 PermissionError
- Dosya başka bir programda açıksa kapatın. Özellikle çıktı PDF'i başka bir PDF okuyucuda açıkken üzerine yazılamaz.

### 🚨 Çok büyük dosyalarda donma
- Çok büyük PDF'ler (> 500 MB) işlenirken birkaç saniye donma olabilir. İşlem bitene kadar bekleyin.

### 🚨 ModuleNotFoundError: fitz (kaynak koddan çalıştırırken)
```bash
# ❌ YANLIŞ
pip install fitz

# ✅ DOĞRU
pip install pymupdf
```
