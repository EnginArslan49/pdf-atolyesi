## 🎯 Proje Hakkında

**PDF Atölyesi**, PDF belgelerini birleştirmek ve belirli sayfalarını ayırmak amacıyla geliştirilmiş, kullanıcı dostu bir masaüstü uygulamasıdır.

Uygulama, karmaşık PDF işlemlerini sade bir arayüz üzerinden kolayca gerçekleştirmeyi sağlar.

İki temel işlem sunar:

- **PDF Birleştirme:** Birden fazla PDF dosyasını tek bir PDF belgesinde birleştirme.
- **PDF Sayfa Ayırma:** İstenilen sayfaları veya sayfa aralıklarını seçerek yeni PDF dosyaları oluşturma.

Uygulama, Python ve CustomTkinter teknolojileri kullanılarak geliştirilmiştir.

**Geliştirici:** Engin ARSLAN  
**Mevcut Sürüm:** v1.0.4  
**Platform:** Windows  
**Ücret:** Tamamen ücretsiz

## ✨ Özellikler

### 🔗 PDF Birleştirme

- Birden fazla PDF dosyasını tek bir dosyada birleştirme.
- Birleştirilecek PDF dosyalarının sırasını değiştirme.
- İstenmeyen dosyaları listeden kaldırma.
- PDF belgelerini birleştirmeden önce önizleme.
- Oluşturulacak PDF dosyasının adını ve kayıt konumunu belirleme.
- Birden fazla PDF belgesiyle kolay çalışma.

### ✂️ PDF Sayfa Ayırma

- PDF içerisindeki sayfaları küçük resimler üzerinden görüntüleme.
- İstenilen sayfaları seçerek ayırma.
- Birden fazla sayfa aralığını aynı anda belirleme.
- Manuel sayfa aralığı girişi.
- Seçilen sayfaları yeni bir PDF dosyasına aktarma.

**Sayfa aralığı örnekleri:**

| Giriş | İşlem |
|---|---|
| `5` | Yalnızca 5. sayfayı ayırır. |
| `1-3` | 1, 2 ve 3. sayfaları ayırır. |
| `1-3,5` | 1, 2, 3 ve 5. sayfaları ayırır. |
| `1-3,5,8-10` | 1, 2, 3, 5, 8, 9 ve 10. sayfaları ayırır. |

### 🎨 Kullanıcı Arayüzü

- Modern ve sade masaüstü arayüzü.
- Koyu tema ve açık tema desteği.
- Ana sayfa üzerinden işlem seçimi.
- İşlemlere özel kullanım rehberi.
- İşlem durumunu gösteren bilgilendirme alanı.
- PDF sayfaları için canlı önizleme.
- Kullanımı kolay dosya yönetimi.

## 📖 Kullanım Rehberi

### 🔗 PDF Birleştirme

1. Uygulamayı çalıştırın.
2. Ana sayfada **PDF Birleştir** seçeneğine tıklayın.
3. **Ekle** butonuyla birleştirmek istediğiniz PDF dosyalarını seçin.
4. Dosyaların sırasını yukarı ve aşağı butonlarıyla düzenleyin.
5. İstemediğiniz dosyaları listeden kaldırın.
6. PDF belgelerini önizleyerek kontrol edin.
7. **PDF'leri Birleştir ve Kaydet** butonuna tıklayın.
8. Yeni dosyanın adını ve kayıt konumunu belirleyin.

**Önemli:** Birleştirme işlemi için en az iki PDF dosyası gereklidir.

### ✂️ PDF Sayfa Ayırma

1. Uygulamayı çalıştırın.
2. Ana sayfada **Sayfa Ayır** seçeneğine tıklayın.
3. **PDF Seç** butonuyla işlem yapılacak PDF dosyasını belirleyin.
4. Sayfaların küçük resimler halinde görüntülenmesini bekleyin.
5. Ayırmak istediğiniz sayfaları seçin.
6. İsterseniz sayfa aralığını manuel olarak da girebilirsiniz.
7. **Ayır ve Kaydet** butonuna tıklayın.
8. Yeni PDF dosyasının adını ve kayıt konumunu belirleyin.

## 🛠️ Geliştiriciler İçin

PDF Atölyesi'nin kaynak kodları GitHub deposunda açık olarak paylaşılmaktadır.

### 📂 Kaynak Kodları

[GitHub – PDF Atölyesi Kaynak Kodları](https://github.com/EnginArslan49/pdf-atolyesi)

### 💻 Gereksinimler

- Python 3.9 veya üzeri.
- pip paket yöneticisi.
- Windows, Linux veya macOS (kaynak koddan çalıştırma için).

### 📦 Gerekli Kütüphaneler

Terminal üzerinden aşağıdaki komutu çalıştırın:

```bash
pip install pypdf pymupdf customtkinter pillow
```

| Kütüphane | Kullanım Amacı |
|---|---|
| `pypdf` | PDF birleştirme ve sayfa ayırma |
| `pymupdf` | PDF önizleme ve sayfa render işlemleri |
| `customtkinter` | Masaüstü kullanıcı arayüzü |
| `pillow` | Görüntü işleme |

### ▶️ Kaynak Koddan Çalıştırma

Projeyi bilgisayarınıza klonlayın:

```bash
git clone https://github.com/EnginArslan49/pdf-atolyesi.git
```

Proje klasörüne geçin:

```bash
cd pdf-atolyesi
```

Gerekli kütüphaneleri yükleyin:

```bash
pip install pypdf pymupdf customtkinter pillow
```

Uygulamayı çalıştırın:

```bash
python Application-Anasayfa.py
```

### 📦 EXE Oluşturma

Kendi Windows çalıştırılabilir dosyanızı oluşturmak için PyInstaller kullanabilirsiniz.

Öncelikle:

```bash
pip install pyinstaller
```

Ardından:

```bash
pyinstaller --noconfirm --onefile --windowed --clean --name "PDF-Atolyesi_EnginARSLAN" --collect-all customtkinter --collect-all pymupdf --hidden-import PIL._tkinter_finder Application-Anasayfa.py
```

Oluşturulan EXE dosyası `dist` klasöründe bulunur.

## ❓ Sorun Giderme

### EXE dosyası açılmıyor

- Dosyanın eksiksiz indirildiğini kontrol edin.
- Windows güvenlik uyarılarını inceleyin.
- Dosyayı resmi GitHub Release sayfasından yeniden indirin.
- Antivirüs tarafından engellenip engellenmediğini kontrol edin.

### PDF önizlemesi görüntülenmiyor

PyMuPDF kütüphanesinin yüklü olduğunu kontrol edin.

```bash
pip install pymupdf
```

### PDF dosyası açılamıyor

- PDF dosyasının bozuk olup olmadığını kontrol edin.
- Şifre korumalı PDF belgeleri desteklenmeyebilir.
- Dosyanın başka bir uygulamada açık olup olmadığını kontrol edin.

### PermissionError hatası

İşlem yapılacak dosyanın başka bir program tarafından kullanılıp kullanılmadığını kontrol edin.
